📘 SmartStudyPro: Owner’s Manual
SmartStudyPro – Educational Resources, Matugga

This guide explains how your website works and how to keep it running smoothly. We built this site to be fast, simple, and "self-fixing."

🌟 How the System Works
Your website has a "Built-in Memory" (a local database). Unlike other sites that rely on complicated external systems, your site saves everything—bookings, orders, and messages—right inside your own hosting folder.

1. The Automatic Helper
The website is smart. If the "memory" file is ever deleted or accidentally moved, the site will automatically recreate it the moment a student clicks "Book." It sets up its own folders and tables so you don't have to.

2. Time & Dates
The site is locked to Uganda Time (East Africa Time). Every order and receipt will show the exact time it happened in Matugga, even if the server is located in another country.

🖥 Using the Admin Dashboard
You have a private area to see your sales and students.

Access: Go to yourdomain.com/admin.php.

Security: You will be asked for a password before you can see any customer data.

Viewing Orders: All new bookings appear at the top. You can see the student's name, what they bought, their phone number, and if they have paid.

📄 Understanding the Receipts
When a customer pays, they get a "Clean Receipt."

Only New Items: If a customer bought a book last week, it won't show up on today's receipt. The system only shows what they just paid for.

Downloads: If they bought a digital PDF, a "Download" button appears automatically on their receipt.

Printing: There is a "Print" button that hides all the website menus and only prints the neat receipt for their records.

🧹 Maintenance (Keeping it Tidy)
Starting a New Term
At the end of a school term, you might want to "empty the bucket" to start fresh for the new year.

The Reset Tool: We have a special tool that wipes the old orders and resets the order numbers back to #1.

Safety: Only run this when you have saved your old records, as this cannot be undone!

Troubleshooting
If the site ever acts "stuck" or shows an error about a "Missing Column":

Go to your file manager.

Find the database folder.

Delete the file inside it.

Done! The site will fix itself on the next click.

💡 Pro-Tips for Success
Folder Permissions: Always make sure your database folder is "Open for Writing" (755) in your hosting settings.

Passwords: Change your admin password once every few months to keep your student data safe.
