# Contributing to SmartStudyPro

SmartStudyPro is a proprietary client application. The repository is public for project visibility and controlled collaboration; it is not an open-source contribution licence.

## Before contributing

- Obtain written approval from the project maintainer before preparing or submitting code, designs, documentation or assets.
- Do not submit client data, credentials, private configuration, database files, backups or copyrighted material without permission.
- Do not add dependencies, analytics, external services or build tooling without approval.
- Preserve the established SmartStudyPro interface, content, responsive behaviour and light/dark themes.
- Keep PHP 8.1 compatibility and shared-hosting constraints.
- Use prepared statements, server-side validation, CSRF protection and role/ownership checks.
- Prefer clear names and small methods; avoid unnecessary comments and dependencies.

## Development checks

Run the PHP lint, unit, SQLite integration, assistant, recognition, operations, content-security, performance and security tests, plus JavaScript syntax and behaviour tests. Changes must pass the PHP 8.1 and 8.3 GitHub Actions matrix.

## Pull requests

Describe the user-visible change, security implications, migration impact, test commands and deployment steps. Include screenshots only when a visual change is required and ensure no personal or production data is visible.

By submitting a contribution, you confirm that you have authority to submit it and agree that, if accepted, it may be incorporated into this proprietary project under the project's ownership and licensing arrangements. A separate written assignment or contributor agreement may be required. Submission alone does not transfer rights or grant you rights to the project.
